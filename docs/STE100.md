# Pull request comment style

Write all pull request review comments in ASD-STE100 Simplified Technical English.

Rules:

1. Use short sentences.
2. Give one instruction per sentence.
3. Use approved common words. Avoid slang.
4. Prefer active voice.
5. Name the file or symbol when you refer to code.
6. Do not use marketing language.

Example:

Incorrect: "This feels a bit messy, maybe rethink the abstraction."

Correct: "Split this function. Move the media rewrite into Media_Sideloader."
